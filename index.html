Installer Code secret

Android · Chrome

Ouvrez le menu ⋮, choisissez « Installer l’application » ou « Ajouter à l’écran d’accueil », puis confirmez l’installation.

iPhone ou iPad · Safari

Ouvrez le menu de partage, puis « Sur l’écran d’accueil ». Activez « Ouvrir comme app web » si l’option est proposée, puis touchez « Ajouter ».

Ordinateur · Chrome ou Edge

Choisissez l’icône d’installation dans la barre d’adresse, ou l’option d’installation du menu du navigateur. Sur Mac avec Safari, utilisez « Fichier » → « Ajouter au Dock » si disponible.

Les intitulés varient selon la version du navigateur. Si aucune option n’est proposée, continuez à jouer dans le navigateur.
